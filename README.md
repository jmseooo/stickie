# Peticker

반려동물 사진에서 **배경을 지워 스티커로 만들고**, 홈 화면 · 잠금 화면 위젯에 올리는 iOS 앱

---

## 소개

반려동물 사진 한 장을 고르면 배경을 지우고, 둘레에 색 테두리를 둘러 스티커로 만듭니다. 완성한 스티커는 홈 화면 위젯과 잠금 화면 위젯에 올릴 수 있습니다.

사진을 오려내는 것 자체보다 **위젯에 올렸을 때 예쁘게 보이는 것**을 목표로 만들었습니다. 그래서 오려낸 결과를 그대로 쓰지 않고 실루엣을 다듬는 과정이 따로 들어가 있습니다.

## 만든 사람

문수영 · 진민서 2인이 함께 만들었습니다. 주로 맡은 부분은 다음과 같습니다.

| | |
| --- | --- |
| **진민서** | 배경 제거와 실루엣 다듬기, 스티커 배치(핀치 · 드래그), 홈 화면 · 잠금 화면 위젯, App Group 공유 저장소, 위젯 배경색, TestFlight 빌드 |
| **문수영** | 스플래시 · 온보딩, 설정 화면(배터리 · 알림 토글, 문의 · 평가), 위젯 추가 안내와 가이드 흐름, 배경 패턴, 스티커 회전, 실패 시 폴백 처리 |

## 사용 흐름

```
사진 선택 → 배경 자동 제거 → 테두리 색 선택 → 위젯 배경 선택
   → 스티커 저장 → 홈 화면 / 잠금 화면에 위젯 추가
```

## 이런 걸 만들었어요

- **또렷한 누끼** — iOS 17+ Vision의 전경 피사체 마스크(`VNGenerateForegroundInstanceMaskRequest`)를 쓰되, 그대로 쓰지 않습니다. Vision 마스크는 경계가 반투명해 위젯에서 뿌옇게 보이기 때문에, **이진화로 반투명 경계를 잘라내고** 잡티와 털 주변의 요철을 정리해 펜으로 그린 듯한 실루엣을 만듭니다 (`BackgroundRemover.swift`)

- **컬러 스트로크** — 오려낸 피사체 둘레에 색 테두리를 둘러 스티커 형태로 완성합니다. 두께는 이미지 크기 대비 비율로 계산해 사진 해상도가 달라도 같은 굵기로 보이고, 번짐(feather) 값으로 하드 엣지와 부드러운 엣지를 조절할 수 있습니다 (`StickerStyler.swift`)

- **위젯 배경** — 단색 6종과 패턴 이미지 8종 중에 고를 수 있습니다. 바탕이 어두우면 위에 얹히는 요소(배터리 표시 등)를 흰색으로 자동 전환하고, 화면 배경과 잘 구분되지 않는 밝은 스와치에는 테두리를 그려 선택지가 묻히지 않게 했습니다

- **두 가지 위젯** — 홈 화면(`systemSmall`)과 잠금 화면(`accessoryCircular`)을 지원합니다

- **앱 ↔ 위젯 데이터 공유** — App Group으로 공유 저장소를 두어, 앱에서 만든 스티커를 위젯 익스텐션이 바로 읽습니다 (`SharedStore.swift`)

- **가이드 오버레이** — 위젯 추가 방법과 배터리 표시 설정을 첫 실행 시 화면 위에 얹어 안내합니다 (`MainGuideOverlay.swift`, `BatteryGuideOverlay.swift`)

## 실행

Xcode에서 `Stickie.xcodeproj`를 열고 실행합니다.

> 저장소와 앱 이름은 **Peticker**, Xcode 프로젝트와 폴더명은 **Stickie**입니다. 초기 이름이 남아 있는 것으로 같은 앱입니다.

앱 타깃과 위젯 타깃의 Signing & Capabilities에 **동일한 App Group**(`group.com.jinminseo.Peticker`)이 등록되어 있어야 위젯이 스티커를 읽을 수 있습니다.

위젯은 시뮬레이터에서도 확인할 수 있지만, **홈 화면 배치와 잠금 화면 동작은 실기기에서 확인하는 것이 정확**합니다.

## 구조

```
Stickie/
├── BackgroundRemover.swift  # 배경 제거 + 실루엣 다듬기
├── StickerStyler.swift      # 컬러 테두리 적용
├── SharedStore.swift        # 앱↔위젯 공유 저장소 (App Group)
├── AppRouter.swift          # 화면 전환
├── MainView.swift           # 메인 · 위젯 미리보기
├── MakeStickieView.swift    # 스티커 제작
├── Colors.swift             # 컬러 정의
└── Typography.swift         # 타이포 정의

StickieWidget/
└── StickieWidget.swift      # 홈 화면 · 잠금 화면 위젯
```
